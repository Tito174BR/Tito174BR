# Manutenção do perfil

1. Altere dados pessoais e preferências em `portfolio.config.json`.
2. Altere textos e estrutura em `README.template.md`.
3. Execute `npm run update`.
4. Execute `npm run check`.
5. Faça commit de `README.md`, `data/portfolio.json` e `assets/generated`.

Os blocos entre marcadores `AUTO` são gerados automaticamente e não devem ser editados diretamente no `README.md`.
